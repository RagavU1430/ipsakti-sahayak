Known Limitations

⚠ These are acknowledged and do NOT block Part 3:

  • No lexical retrieval yet — Vector-only. Hybrid retrieval in Part 3.
  • No reranking — Basic top-K only. Reranking in Part 3.
  • No generation — Retrieval only. Generation in Part 3+.
  • Model not specialized — General-purpose embedding, not optimized for legal domain. Acceptable for foundation.
  • Multilingual limitations — Non-English retrieval may be suboptimal.
  • Rate limiting — OpenRouter enforces per-minute limits.
  • No offline fallback — Requires internet and API key.

Environment Variables Required

Before running Part 2 pipeline:

  • OPENROUTER_API_KEY — OpenRouter authentication
  • V2_EMBEDDING_PROVIDER — Provider selection (default: openrouter)
  • V2_EMBEDDING_MODEL — Model ID
  • V2_EMBEDDING_DIMENSION — Vector size
  • V2_CORPUS_VERSION — Corpus version identifier
  • V2_EMBEDDING_VERSION — Embedding version identifier
