Phase 3: Legal Term Extraction

Exact legal identifiers for lexical retrieval:

  • Act names (Patents Act 1970, Trademarks Act 1999, etc.)
  • Section numbers (Section 3(d), Rule 9, etc.)
  • WIPO/International references (Paris Convention, PCT, TRIPS, etc.)
  • Regulatory references (FSSAI, Ayurveda Aahara Order, etc.)
  • Organization names (Ministry of AYUSH, NBA, WIPO, etc.)

Status: ✅ Implementation complete

Phase 4: Lexical Retrieval

PostgreSQL full-text search with four matching strategies:

  • Exact: Case-insensitive substring match
  • Phrase: PostgreSQL ts_query with phrase proximity
  • Partial: Prefix and substring matching
  • Semantic: Full-text search with ts_rank scoring

Status: ✅ Implementation complete

Phase 7: Hybrid Retrieval

Vector + Lexical fusion using Reciprocal Rank Fusion (RRF):

  • Execute vector search (K=20)
  • Execute lexical search (K=20)
  • Deduplicate by chunk_id
  • Fuse using RRF (robust, no tuning)
  • Return top 10 results

Status: ✅ Implementation complete

Phase 10: Domain-Aware Retrieval

Optional domain filtering with graceful fallback:

  • High confidence (>0.4): Prioritize primary domain matches
  • Low confidence: Fall back to pure hybrid ranking
  • Preserve other domain results (prevent false negatives)

Status: ✅ Implementation complete

Phase 12: Reranking

Two lightweight reranking strategies:

  • Lexical Boosting: Boost scores by query term frequency in content
  • Domain Ranking: Boost scores by domain relevance

Status: ✅ Implementation complete

Implementation Details: Hybrid Fusion (RRF)

Reciprocal Rank Fusion formula:

RRF Score = Σ 1 / (k + rank)
k = 60 (constant)
rank = position in vector/lexical results

Advantages:

  • No tuning needed (no weights to adjust)
  • Robust to different score distributions
  • Works well with vector (0-1 similarity) and lexical (0-∞ tf-idf) scores
  • Well-studied in information retrieval literature
