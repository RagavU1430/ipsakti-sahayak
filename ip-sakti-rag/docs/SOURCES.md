# Sources

Primary authorities are India Code, IP India, Ministry of Ayush/PCIM&H, National Biodiversity Authority, FSSAI, WTO, WIPO, and TKDL. Every registered URL uses an official domain. Search results and third-party mirrors are never source records.

India Code landing pages are retained when the official direct file endpoint is not yet confirmed. WIPO treaty landing pages are retained for the same reason. TKDL is registry metadata only (`RESTRICTED`, `content_available=false`); authentication and technical controls must not be bypassed.

The Ministry of Ayush annual/statistical reports provide official context but are not substitutes for pharmacopoeial monographs or Gazette legal text. The Patents Rules direct file is explicitly labelled as updated only through 23 June 2017 and must not be represented as the current consolidated rules.

Accessibility incidents are preserved in registry notes and the acquisition report. A timeout, anti-bot HTML response, CAPTCHA, or missing direct link is a reason to leave content pending or failed, not to substitute a non-official copy.
